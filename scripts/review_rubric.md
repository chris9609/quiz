# 候補レビューの採否基準

`data/candidates.json` の `status: pending` を採用（approved）／見送り（rejected）に振り分けるときの基準。
レビューは Claude（Claude Code のセッション）が行う。人が判断していた頃の基準を明文化したもの。

判定時は `status` と一緒に `review_reason` を書き、あとから理由を追えるようにする。

## 見送りにするもの

1. **答えがマニアックすぎる** — 早押しクイズとして、一般的な知識で答えに辿り着けないもの。
   目安: 答えを聞いて「ああ、あれね」とならないもの。
   例: 「江戸城跡のヒカリゴケ生育地」「器楽的幻覚」（無名の短編小説）
2. **ジャンルが合わない** — 18禁ゲーム、成人向け作品、特定の宗教・政治的主張に踏み込むもの。
3. **日本語が不自然** — 疑問文として成立していない、文末が変。
   例: 「〜に名前を起源とする？」
4. **問題文だけでは答えが一意に絞れない** — 複数の答えが成り立つ。
5. **事実誤認の疑い** — 出典（source_url）と照らして問題文の記述が怪しいもの。

## 採用するもの

- 上の5つに当てはまらず、「知っている人ならわかる」レベルの一般教養・雑学・スポーツ・科学・地理・歴史・有名作品。
- 問題文が長めでも、早押しなので冒頭で当てられる構造になっていれば良い（ヒントが徐々に具体化する形が理想）。

## 迷ったとき

- マニアックかどうかで迷ったら見送る。DB に入ると全プレイヤーに出題されるので、当たらない問題は体験を悪くする。
- 日本語が少し硬い程度なら採用してよい。

## 機械的に落とすもの（ここでは判定しない）

文字数・答えの露出・多文構成・読みの有無・重複・天然記念物系タイトル（〜生育地/自生地/生息地）は
`generate_quiz.py` の `validate()` で落ちるので、レビューには来ない。
